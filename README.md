# Chairman of Chaos

A portrait, touch-first 3D office rodeo. Drag the lower pad to counterbalance the wobbling furniture. The dot should stay in the mint lane. Large left/right buttons and A/D or arrow keys also work.

Six automatically revealed episodes run through three office sets. Every completed attempt opens the next scene, including a failed ride. Best stars persist. Checkpoints resume at the same elapsed time with neutral input. The game's isolated save key is chairman-of-chaos-v1.

Both index.html and standalone.html contain every runtime asset and need WebGL. Open either entry offline, or host the folder. Rebuild using node build.cjs. Three.js is bundled under MIT in vendor/.

GameWave support uses real seat-start and resolved-ride events, independent from rendering and standalone startup. Confirmed positive like and direct comment callbacks unlock optional suit colors with persistent flags. Cloud data contains only this game's state. Tests distinguish mocks and browser verification from actual App-host testing. No actual GameWave App or physical handset verification is claimed.

The game, models and synthesized audio are original. Rezona Table Top Turbo was inspected for toy-scale room presentation, including its native start scene. No reference source, artwork or audio is copied.
